# TaxCLI v0.1.1

TaxCLI 0.1.1 builds on the previous public release, **v0.1.0**, with agent management, model comparisons, mobile access, and development tools. Source code is available on `main` and under the `v0.1.1` tag.

## Features retained from v0.1.0

- Codex, OpenCode, Cursor Agent, GitHub Copilot, Gemini CLI, and NVIDIA models in one Windows workspace.
- Project-scoped local conversations, model selection, and streamed responses.
- Project memory and provider-specific agent instruction files.
- An integrated PowerShell terminal, local image attachments, and execution permissions.
- Windows installer distribution through GitHub Releases.

## New in this release

### Agents and models

- Claude Code support with official installation and sign-in flows.
- Planner, everyday assistant, coder, and analyst profiles, with automatic specialist selection based on the request.
- Provider-local Auto and cross-provider Global Auto, with Economy, Balanced, and Quality routing policies.
- A keyboard-accessible menu for profile, routing policy, and reasoning effort.
- A searchable, grouped comparison selector supporting multiple models from the same provider.
- Codex app-server integration and expanded adapters for provider-reported usage data.

### AI Office and accounts

- Customizable AI Office teams with named employees, roles, and manager-led task delegation.
- Subagent task queues, bounded concurrency, and result synthesis.
- Encrypted ChatGPT account profiles and separate account assignments for Codex employees.
- Statistics for duration, model/provider usage, estimated cost, success, and file changes.

### Development Center

- File- and hunk-level reviews, accept/reject actions, selective solution application, and per-run undo.
- Conflict checks and safety snapshots before changes.
- Model Arena: independent workspaces from the same baseline, automatic tests, anonymous judging, and separate scoring metrics.
- Encrypted run records, tool/command/approval timelines, export, and replay.
- Built-in and custom task recipes, project health checks, independent conversation branches, and branch comparison/merge.
- Local text/PDF knowledge documents, CLI session import, and provider diagnostics.

### Mobile, Git, and integrations

- Local-network mobile chat with single-use QR pairing and revocable device sessions.
- Per-phone project, provider/model, and approval-mode selection, with approvals synchronized to the desktop.
- Separate mobile conversations that preserve the desktop's open conversation and draft.
- Persistent task queues with pause, retry, and restart recovery.
- Git Center: status, stage/unstage, repository initialization, commit history, and commits.
- Version-pinned MCP templates with visible permissions, plus Cloudflare account and zone integration.

## Interface and Windows fixes

- Theme-aware project context menus and in-app confirmation dialogs.
- Compact folder/conversation lists with hover actions, pinning, archiving, and restoration from the archive.
- A searchable add menu opening above the full message input at the same width.
- Shared access to attachments, workflows, described plugins, and existing tools, with arrow-key and Escape support.
- Borderless profile/policy/effort controls and a responsive composer footer.
- A neutral dark theme, the Midnight theme preserving the previous appearance, and light-theme compatibility.
- Multi-resolution Windows icons and TaxCLI identity for the window, taskbar, and development launcher.
- Chromium origin-check compatibility for mobile pairing and an improved mobile chat layout.

## Security and data storage

- Windows-backed encryption for provider keys, account credentials, and vault secrets, with migration of legacy plaintext keys.
- Workspace trust, sensitive-file exclusions, execution limits, and dangerous-command controls.
- Hash-chained audit records with secret redaction.
- Permission, download, popup, and navigation restrictions in the embedded browser.
- A CycloneDX dependency inventory and SHA-256 checksums for downloadable assets.
- Security updates for Electron and development dependencies; the full dependency audit found no known vulnerabilities at release time.

## Installation and upgrade

1. Download `TaxCLI-Setup-0.1.1.exe` from this release's assets.
2. Finish any active tasks and close TaxCLI using **Exit** in its system-tray menu.
3. Run the Windows x64 installer and reopen the application.

**Signing status:** Like v0.1.0, this installer is not yet Authenticode-signed. Use `SHA256SUMS.txt` to verify the downloaded files. No `latest.yml` is published for this unsigned release, so upgrading to v0.1.1 requires manual installation. The automated signed-release pipeline does not publish until signing credentials are configured.

**Requirements:** Windows 10 or later (x64) and the installed, authenticated CLI for your chosen provider. Running from source requires Node.js 22.13 or later.

Mobile access is limited to the local network. Some areas, including AI Office, Model Arena, and the embedded browser, remain experimental. Provider usage charges are managed by the respective providers.
