# TaxCLI v0.1.2

This patch fixes Windows startup, Codex CLI discovery and Model Arena judging, and improves comparison progress and history.

## Fixes and changes

- Windows packages use the standard V8 snapshot and the file protocol support needed to load the interface, fixing crashes before the window opens and blank startup windows.
- Codex discovery prefers the standalone npm CLI and excludes the Microsoft Store desktop launcher. Sign-in terminals start in the user's home folder.
- Judge reports keep every candidate within the context budget instead of cutting off the serialized solution list. Completed solutions are explicitly listed for scoring, and missing scores identify the affected candidates.
- Comparisons keep model and judge outputs in one conversation, show live progress and provider errors, and use isolated workspaces under the selected project.
- Locked candidate files no longer block subsequent models. Cleanup can be retried, and comparisons with no successful candidates skip judging.
- Approval dialogs show the requesting run's permission mode. Eligible Codex requests use Auto-review while retaining the workspace sandbox.
- AI Office, Development Center, subagent teams and Multi-AI comparison display Beta labels.

## Installation and upgrade

1. Download `TaxCLI-Setup-0.1.2.exe` from the release assets.
2. Finish active tasks and exit TaxCLI through its system-tray menu.
3. Run the installer and reopen TaxCLI. Existing projects, conversations and account data remain in place.

**Signing status:** This is an unsigned Windows x64 installer, as in v0.1.1. Verify downloaded assets against `SHA256SUMS.txt`. No `latest.yml` is published for this unsigned release; install the update manually. The signed automatic-release workflow remains unchanged.
